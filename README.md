# IainTris

IainTris is an unofficial Tetris-inspired block-stacking game for the Playdate.
It is built in Lua with the Playdate SDK and includes Playdate-specific niceties
like crank-assisted dropping, system menu settings, persistent high scores,
custom fonts, generated launcher artwork, and bundled sound effects made with
Playdate synths.

## Features

- Classic 10 x 20 tetromino playfield
- SRS-style rotation with wall kicks
- Score, level, lines, next-piece preview, and high score tracking
- Optional ghost piece
- Optional 7-bag randomizer
- Two block styles: **Shaded** (dithered fills) and **Hatched** (matches the launcher art)
- Soft drop, hard drop, and a real-time lock delay (450 ms, up to 15 move/rotate resets per row)
- Crank input for accelerated dropping
- Animated line clears and game-over stats
- Pause stats shown beside the Playdate system menu
- Playdate system menu items for 7-bag mode, ghost piece, and credits
- Catalog and launcher artwork generated by `tools/generate_brand_assets.py`

## Controls

| Input | Action |
| --- | --- |
| A | Start game / rotate piece clockwise |
| B | Toggle 7-bag on the title screen / hard drop during play |
| Left / Right | Change block style on the title screen / move piece |
| Down | Soft drop |
| Crank | Drop faster when undocked |
| Menu | Pause and open the Playdate system menu |

On the credits and game-over screens, press A or B to continue. Opening the
credits during a run keeps the run; closing them resumes play.

## Requirements

- Playdate SDK
- `pdc` available on your shell path
- Playdate Simulator, or a Playdate device for sideloading

## Build

From the project root:

```sh
pdc source IainTris.pdx
```

Only `source/` is compiled, so tools, docs and catalog art stay out of the bundle.

## Run In Simulator

After building, open the bundle in Playdate Simulator:

```sh
open -a "Playdate Simulator" IainTris.pdx
```

You can also drag `IainTris.pdx` onto the simulator.

## Assets

Launcher art lives in `source/assets/launcher/`; catalog art lives in
`assets/catalog/`. To regenerate both:

```sh
python3 tools/generate_brand_assets.py
```

Then rebuild with `pdc`.

## Save Data

The game persists high score and settings with Playdate datastore under:

```text
tetris_save
```

Saved values: high score, ghost piece, 7-bag mode, and block style. The high
score is written at game over, when the game pauses, sleeps or quits.
